### ALGO-000143: Sampling equitable colorings near q = Δ
- **Subfield:** Approximate counting, sampling, and average-case complexity
- **Open:** Approximately uniformly sample proper colorings with prescribed balanced color-class sizes when \(q\ge(1+\varepsilon)\Delta\), for fixed \(\varepsilon>0\).
- **Status:** Kuchukova–Perkins–Povill’s 2026 work gives polynomial-time sampling in a regime above \(2\Delta\). Closing the palette gap is open.
- **Type:** theory
- **Why:** Adds global conservation constraints absent from ordinary coloring samplers.
- **Key works:** Kuchukova, Perkins, and Povill (2026), *Sampling Colorings with Fixed Color Class Sizes*, arXiv:2603.08259.
- **Related:** Statistical mechanics—canonical ensembles with fixed species counts.
